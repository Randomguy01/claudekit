# Operation.State.IN_PROGRESS

> Added in 1.0.0

```
class Operation.State.IN_PROGRESS : Operation.State
```

Represents an [`Operation`](operation.md) which is in progress. This is not a terminal state and is never reported by [`Operation.getResult`](operation.md#getresult).
