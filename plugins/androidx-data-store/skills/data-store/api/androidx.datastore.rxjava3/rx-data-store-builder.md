# API Reference

> Last updated 2026-06-10

# RxDataStoreBuilder

> Added in 1.0.0

```
class RxDataStoreBuilder<T : Any>
```

Builder for an [`RxDataStore`](rx-data-store.md) that works on a single process.

## Public Constructors

### RxDataStoreBuilder

```
<T : Any> RxDataStoreBuilder(
    produceFile: Callable<File>,
    serializer: Serializer<T>
)
```

Create a builder with the `Callable` which returns the `File` that DataStore acts on. You are responsible for ensuring there is never more than one DataStore acting on a file at a time.

- `produceFile` — function which returns the file the new DataStore will act on. Must return the same path every time.
- `serializer` — the [`Serializer`](../androidx.datastore.core/serializer.md) for the type this DataStore acts on.

### RxDataStoreBuilder

```
<T : Any> RxDataStoreBuilder(
    context: Context,
    fileName: String,
    serializer: Serializer<T>
)
```

Create a builder with the `Context` and name from which to derive the DataStore file, generated by `File(this.filesDir, "datastore/$fileName")`. You are responsible for ensuring there is never more than one DataStore acting on a file at a time.

- `context` — the context from which the files directory is retrieved.
- `fileName` — the filename relative to `Context.applicationContext.filesDir`, created in the `datastore/` subdirectory.
- `serializer` — the [`Serializer`](../androidx.datastore.core/serializer.md) for the type this DataStore acts on.

## Public Functions

### addDataMigration

```
fun addDataMigration(dataMigration: DataMigration<T>): RxDataStoreBuilder<T>
```

Add a [`DataMigration`](../androidx.datastore.core/data-migration.md) to the DataStore. Migrations run in the order they are added. Returns `this`.

### addRxDataMigration

```
fun addRxDataMigration(rxDataMigration: RxDataMigration<T>): RxDataStoreBuilder<T>
```

Add an [`RxDataMigration`](rx-data-migration.md) to the DataStore. Migrations run in the order they are added. Returns `this`.

### setCorruptionHandler

```
fun setCorruptionHandler(
    corruptionHandler: ReplaceFileCorruptionHandler<T>
): RxDataStoreBuilder<T>
```

Sets the [`ReplaceFileCorruptionHandler`](../androidx.datastore.core.handlers/replace-file-corruption-handler.md) to install into the DataStore. Optional; defaults to no corruption handler. Returns `this`.

### setIoScheduler

```
fun setIoScheduler(ioScheduler: Scheduler): RxDataStoreBuilder<T>
```

Set the `Scheduler` on which IO and transform operations run; it is converted into a `CoroutineDispatcher` before being added to DataStore. Optional; defaults to `Schedulers.io()`. Returns `this`.

### build

```
fun build(): RxDataStore<T>
```

Build the [`RxDataStore`](rx-data-store.md) with the provided parameters.
