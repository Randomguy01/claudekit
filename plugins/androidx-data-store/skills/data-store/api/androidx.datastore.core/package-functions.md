# androidx.datastore.core — Top-Level & Extension Functions

The package-level helper functions in `androidx.datastore.core`. The types they reference (`DataStore`, `Storage`, `StorageConnection`, `InterProcessCoordinator`, `Closeable`) are documented in the per-type files in this directory.

## Top-Level Functions

### createMultiProcessCoordinator

> Added in 1.1.0

**Android**

```
fun createMultiProcessCoordinator(context: CoroutineContext, file: File): InterProcessCoordinator
```

Create an [`InterProcessCoordinator`](inter-process-coordinator.md) for multiple-process use cases.

- `context` — the coroutine context used by the coordinator for IO operations.
- `file` — the file in which [`DataStore`](data-store.md) stores the data.

### createSingleProcessCoordinator

> Added in 1.1.0

**Android**

```
fun createSingleProcessCoordinator(file: File): InterProcessCoordinator
```

Create an [`InterProcessCoordinator`](inter-process-coordinator.md) for single-process use cases.

- `file` — the canonical file managed by the coordinator.

## Extension Functions

### Context.deviceProtectedDataStoreFile

> Added in 1.2.0

**Android**

```
@RequiresApi(value = 24)
fun Context.deviceProtectedDataStoreFile(fileName: String): File
```

Generate the `File` object for a DataStore for use during direct boot. If the provided context is a user-encrypted context, it is converted to a device-protected storage context via `Context.createDeviceProtectedStorageContext()`. The file is generated by calling `File(deviceProtectedContext.filesDir, "datastore/$fileName")`.

Do **not** use the file outside of DataStore.

- `fileName` — the file name.

### StorageConnection.readData

```
suspend fun <T : Any?> StorageConnection<T>.readData(): T
```

Reads the data from a [`StorageConnection`](storage-connection.md).

### StorageConnection.writeData

> Added in 1.1.0

```
suspend fun <T : Any?> StorageConnection<T>.writeData(value: T): Unit
```

Writes `value` to a [`StorageConnection`](storage-connection.md).

### T.use

> Added in 1.1.0

```
inline fun <T : Closeable, R : Any?> T.use(block: (T) -> R): R
```

Ensures a [`Closeable`](closeable.md) object has its `close()` method called at the end of `block`. Any exceptions thrown in `block` propagate through this method.
