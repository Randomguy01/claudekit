# RxPreferenceDataStoreBuilder

> Added in 1.0.0

```
class RxPreferenceDataStoreBuilder
```

Builder for a Preferences [`RxDataStore`](../androidx.datastore.rxjava3/rx-data-store.md) that works on a single process.

## Public Constructors

### RxPreferenceDataStoreBuilder

```
RxPreferenceDataStoreBuilder(produceFile: Callable<File>)
```

Create a builder with the `Callable` which returns the `File` that DataStore acts on. You are responsible for ensuring there is never more than one DataStore acting on a file at a time.

- `produceFile` — function which returns the file the new DataStore will act on. Must return the same path every time.

### RxPreferenceDataStoreBuilder

```
RxPreferenceDataStoreBuilder(context: Context, name: String)
```

Create a builder with the `Context` and name from which to derive the DataStore file, generated by `File(context.filesDir, "datastore/" + name + ".preferences_pb")`. You are responsible for ensuring there is never more than one DataStore acting on a file at a time.

- `context` — the context from which the files directory is retrieved.
- `name` — the filename relative to `Context.filesDir` that DataStore acts on, created in the `datastore/` subdirectory with the `.preferences_pb` extension.

## Public Functions

### addDataMigration

```
fun addDataMigration(dataMigration: DataMigration<Preferences>): RxPreferenceDataStoreBuilder
```

Add a [`DataMigration`](../androidx.datastore.core/data-migration.md) to the DataStore. Migrations run in the order they are added. Returns `this`.

### addRxDataMigration

```
fun addRxDataMigration(rxDataMigration: RxDataMigration<Preferences>): RxPreferenceDataStoreBuilder
```

Add an [`RxDataMigration`](../androidx.datastore.rxjava3/rx-data-migration.md) to the DataStore. Migrations run in the order they are added. Returns `this`.

### setCorruptionHandler

```
fun setCorruptionHandler(
    corruptionHandler: ReplaceFileCorruptionHandler<Preferences>
): RxPreferenceDataStoreBuilder
```

Sets the [`ReplaceFileCorruptionHandler`](../androidx.datastore.core.handlers/replace-file-corruption-handler.md) to install into the DataStore. Optional; defaults to no corruption handler. Returns `this`.

### setIoScheduler

```
fun setIoScheduler(ioScheduler: Scheduler): RxPreferenceDataStoreBuilder
```

Set the `Scheduler` on which IO and transform operations run; it is converted into a `CoroutineDispatcher` before being added to DataStore. Optional; defaults to `Schedulers.io()`. Returns `this`.

### build

```
fun build(): RxDataStore<Preferences>
```

Build the [`RxDataStore`](../androidx.datastore.rxjava3/rx-data-store.md) of [`Preferences`](../androidx.datastore.preferences.core/preferences.md) with the provided parameters. Throws `IllegalStateException` if the serializer is not set, or if neither `produceFile` nor `context` and `name` are set.
