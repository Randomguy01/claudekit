# RoomDatabase

> Added in 2.0.0

```
abstract class RoomDatabase
```

Base class for all Room databases. All classes that are annotated with [`@Database`](database.md) must extend this class.

`RoomDatabase` provides direct access to the underlying database implementation, but you should prefer using [`@Dao`](dao.md) classes.

### clearAllTables

**Android**
> Added in 2.0.0
```
@WorkerThread
abstract fun clearAllTables(): Unit
```

Deletes all rows from all the tables that are registered to this database as `Database.entities`.

This does NOT reset the auto-increment value generated by `PrimaryKey.autoGenerate`. After deleting the rows, Room sets a WAL checkpoint and runs `VACUUM`, so the data is completely erased. The space is reclaimed by the system if the amount surpasses the threshold of database file size.

## Extension Functions

### invalidationTrackerFlow

**Android**
```
fun RoomDatabase.invalidationTrackerFlow(
    vararg tables: String,
    emitInitialState: Boolean = true
): Flow<Set<String>>
```

**Deprecated — replaced by the equivalent API in `InvalidationTracker`.**

Creates a `Flow` that listens for changes in the database via the `InvalidationTracker` and emits sets of the tables that were invalidated. The Flow emits at least one value — a set of all the tables registered for observation — to kick-start the stream, unless `emitInitialState` is `false`. Throws `IllegalArgumentException` if one of the tables to observe does not exist.

```kotlin
fun getArtistTours(from: Date, to: Date): Flow<Map<Artist, TourState>> {
  return db.invalidationTrackerFlow("Artist").map { _ ->
    val artists = artistsDao.getAllArtists()
    val tours = tourService.fetchStates(artists.map { it.id })
    associateTours(artists, tours, from, to)
  }
}
```

- `tables` — The names of the tables or views to observe.
- `emitInitialState` — Set to `false` if no initial emission is desired. Default is `true`.

### useReaderConnection

```
suspend fun <R : Any?> RoomDatabase.useReaderConnection(block: suspend (Transactor) -> R): R
```

Acquires a READ connection, suspending while waiting if none is available, then runs `block` with it. A `RoomDatabase` has one or more READ connections. The connection is an instance of `Transactor` that supports nested transactions.

Using the connection after the call completes is prohibited. The connection is confined to the coroutine on which the function executes; using it from a different coroutine results in an error. If the current coroutine already has a confined connection, that connection is used. A `SQLiteException` is thrown if acquiring a connection times out.

- `block` — The code to use the connection.

### useWriterConnection

```
suspend fun <R : Any?> RoomDatabase.useWriterConnection(block: suspend (Transactor) -> R): R
```

Acquires the WRITE connection, suspending while waiting if it is unavailable, then runs `block` with it. A `RoomDatabase` has only one WRITE connection. The connection is an instance of `Transactor` that supports nested transactions.

Using the connection after the call completes is prohibited. The connection is confined to the coroutine on which the function executes. If the current coroutine already has a confined connection, that connection is used as long as it doesn't need to be upgraded to a writer; if an upgrade is required, a `SQLiteException` is thrown. A `SQLiteException` is also thrown if acquiring a connection times out.

- `block` — The code to use the connection.

### withTransaction

**Android**
```
suspend fun <R : Any?> RoomDatabase.withTransaction(block: suspend () -> R): R
```

Calls the specified suspending `block` in a database transaction. The transaction is marked as successful unless an exception is thrown in the block or the coroutine is cancelled. Room performs at most one transaction at a time; additional transactions are queued and executed on a first-come, first-served order.

Performing blocking database operations is not permitted in a coroutine scope other than the one received by the block. It is recommended that all `@Dao` functions invoked within the block be suspending functions.
