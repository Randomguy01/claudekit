# ConstructedBy

> Added in 2.7.0

**Common**
```
@Target(allowedTargets = [AnnotationTarget.CLASS])
@Retention(value = AnnotationRetention.BINARY)
annotation ConstructedBy
```

**Native / JS**
```
@Target(allowedTargets = [AnnotationTarget.CLASS])
@Retention(value = AnnotationRetention.BINARY)
annotation ConstructedBy
```

Defines the `RoomDatabaseConstructor` that will instantiate the Room-generated implementation of the annotated [`@Database`](database.md).

A [`RoomDatabase`](room-database.md) definition must be annotated with this annotation if it is located in a common source set on a Kotlin Multiplatform project, so that at runtime the implementation generated by the annotation processor can be used. The `value` must be an `expect object` that implements `RoomDatabaseConstructor`.

```kotlin
@Database(version = 1, entities = [Song::class, Album::class])
@ConstructedBy(MusicDatabaseConstructor::class)
abstract class MusicDatabase : RoomDatabase

expect object MusicDatabaseConstructor : RoomDatabaseConstructor<MusicDatabase>
```
